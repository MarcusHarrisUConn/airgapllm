# Getting Started with airgapllm: Air-Gapped Local AI Workflows in R

## Overview

Clinical, behavioral, educational, and medical researchers routinely
analyze rich unstructured text—therapy progress notes, EMA journals,
student writing, and patient narratives—that **cannot be transmitted to
external cloud LLM APIs** under IRB, HIPAA, or FERPA data-use
agreements.

`airgapllm` provides a complete, privacy-first R workbench for
**verifiably offline local LLM workflows**:

1.  **Air-Gapped Container Lifecycle Manager**: Generate pinned,
    hardened Docker (`--network none`, `--read-only`, `--cap-drop ALL`)
    and HPC Apptainer `.def` configurations for `Ollama`, `llama.cpp`,
    and `vLLM`, verify local model weight SHA-256 digests, and run
    automated pre-flight isolation checks.
2.  **Pre-Inference Privacy & PII Engine**: Detect, redact, or
    reversibly pseudonymize (HMAC-SHA256 + AES-256-CBC encrypted vault)
    direct identifiers in pure R before any text reaches the model.
3.  **Crash-Resumable Schema-Enforced Batch Extractor**: Extract
    strictly typed tibbles from R data frames with automated repair
    retries for malformed outputs and atomic per-row JSONL
    checkpointing.
4.  **Immutable Audit Trail & IRB Protocol Generator**: Maintain
    tamper-evident SHA-256 hash-chained JSONL logs (strictly barring raw
    text/PII) and generate ready-to-paste IRB/HIPAA Methods boilerplate.

Everything in this vignette runs 100% offline using the built-in
deterministic
[`runtime_mock()`](https://marcusharrisphd.com/airgapllm/reference/runtime_mock.md),
while producing the exact container configurations, schemas,
checkpoints, audit logs, and IRB narratives used in production on local
GPU workstations and HPC nodes.

``` r

library(airgapllm)
library(tibble)
```

## Step 4: Execute Crash-Resumable, Schema-Enforced Batch Extraction

Now run
[`airgap_extract()`](https://marcusharrisphd.com/airgapllm/reference/airgap_extract.md)
with:

- Mandatory pre-inference PII redaction (`pii_policy = "redact"`),
- Simulated malformed JSON on `NOTE_02` to demonstrate automatic
  structured repair retries,
- Atomic row-level checkpointing (`checkpoint_path`), and
- Automatic hash-chained IRB/HIPAA audit logging (`audit_log_path`).

In production on a local GPU workstation, swap
[`runtime_mock()`](https://marcusharrisphd.com/airgapllm/reference/runtime_mock.md)
for `runtime_ollama("llama3.1:8b-instruct-q4_K_M")` or
`runtime_openai_local("llama-3.1-8b", base_url = "http://127.0.0.1:8080/v1")`.

``` r

ck_path <- tempfile(fileext = ".checkpoint.jsonl")
audit_path <- tempfile(fileext = ".audit.jsonl")

rt <- runtime_mock(
  model = "llama-3.1-8b-instruct-q4_K_M",
  seed = 2026L,
  malform_schedule = list(
    NOTE_02 = c(
      "{truncated_json",
      '{"sentiment":"very_bad","severity":99,"confidence":0.8,"crisis_flag":false}'

)

extracted <- airgap_extract(
```
