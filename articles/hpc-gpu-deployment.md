# HPC & GPU Workstation Deployment: VRAM Sizing, Containers, and Long-Transcript Chunking

## Overview

Deploying open-weights LLMs (`Llama`, `Qwen`, `Gemma`, `Mistral`) on
departmental GPU workstations or university HPC Slurm nodes introduces
practical engineering challenges that go beyond calling a local HTTP
port:

- **GPU Out-of-Memory (OOM) Failures**: Selecting a quantization level
  and context window that exceeds available VRAM.
- **Strict Air-Gapping**: Ensuring Docker and Apptainer containers
  cannot make outbound network calls, download telemetry, or escape
  mounted model directories via symlinks.
- **Long Qualitative Transcripts**: Therapy transcripts and
  semi-structured interviews frequently exceed 4,096–8,192 tokens and
  require deterministic overlapping chunking prior to extraction.
- **Walltime Preemption & Schema Drift**: Resuming 50,000-row batches
  cleanly after Slurm preemption while blocking accidental schema or
  prompt mismatches.

``` r
library(airgapllm)
```

## 2. Hardened `--network none` Docker & HPC Apptainer Configurations

Pin both the container image digest (`sha256:...`) and local model
weight digest
([`verify_model_digest()`](https://marcusharrisphd.com/airgapllm/reference/verify_model_digest.md))

``` r
writeBin(charToRaw("synthetic-local-gguf-weights-for-vignette"), weights_file)

# Verify streaming SHA-256 (blocks symlinks & path escapes by default)
```

## 3. Deterministic Chunking for Long Clinical Transcripts

When transcripts exceed local context windows, split them
deterministically along paragraph or sentence boundaries using
[`chunk_clinical_texts()`](https://marcusharrisphd.com/airgapllm/reference/chunk_clinical_texts.md)
while retaining `doc_id`, `chunk_id`, and exact character offsets for
downstream re-aggregation:

``` r

data("synthetic_notes", package = "airgapllm")
long_record <- synthetic_notes[synthetic_notes$note_id == "SYN_016", ]

chunks <- chunk_clinical_texts(
  data = long_record,
  text_col = "note_text",
  id_col = "note_id",
  max_chars = 340L,
  overlap_chars = 50L,
  split_on = "paragraph"
)
chunks[, c("doc_id", "chunk_id", "chunk_index", "n_chunks", "start_char", "end_char", "char_count")]
#> # A tibble: 3 × 7
#>   doc_id  chunk_id          chunk_index n_chunks start_char end_char char_count
#>   <chr>   <chr>                   <int>    <int>      <int>    <int>      <int>
#> 1 SYN_016 SYN_016_chunk_001           1        3          1      251        251
#> 2 SYN_016 SYN_016_chunk_002           2        3        208      498        291
#> 3 SYN_016 SYN_016_chunk_003           3        3        452      715        264
```

Run
[`airgap_extract()`](https://marcusharrisphd.com/airgapllm/reference/airgap_extract.md)
directly over `chunks` using `id_col = "chunk_id"` so every chunk is
independently PII-redacted, schema-validated, and checkpointed:

``` r

chunk_schema <- extraction_schema(
  topic = schema_field("enum", values = c("sleep", "coping", "logistics", "other")),
  crisis_flag = schema_field("logical")
)

ck_file <- file.path(work_dir, "chunks_checkpoint.jsonl")
chunk_res <- airgap_extract(
  data = chunks,
  text_col = "chunk_text",
  schema = chunk_schema,
  runtime = runtime_mock(seed = 77L),
  id_col = "chunk_id",
  checkpoint_path = ck_file,
  container_spec = spec,
  model_path = weights_file
)

chunk_res[, c("chunk_id", "topic", "crisis_flag", ".status")]
#> # A tibble: 3 × 4
```

## 4. Checkpoint Schema-Drift Guards & Offline Troubleshooting

If an analyst edits the extraction schema or prompt template mid-study
and accidentally points
[`airgap_extract()`](https://marcusharrisphd.com/airgapllm/reference/airgap_extract.md)
at an old `checkpoint_path` with `resume = TRUE`, `airgapllm` refuses to
silently mix incompatible schemas:

``` r

modified_schema <- extraction_schema(
  topic = schema_field("enum", values = c("sleep", "coping", "logistics", "other")),
  severity = schema_field("integer", min = 0L, max = 5L)
)

tryCatch(
  airgap_extract(
    data = chunks,
    text_col = "chunk_text",
    schema = modified_schema,
    runtime = runtime_mock(seed = 77L),
    id_col = "chunk_id",
    checkpoint_path = ck_file,
    resume = TRUE
  ),
  airgap_checkpoint_error = function(e) {
    message("Guardrail triggered: ", conditionMessage(e))
  }
)
#> Guardrail triggered: Checkpoint schema mismatch: cannot resume into a different extraction
#> schema.
#> ✖ Checkpoint schema digest:
#>   sha256:ccffa19b89f611e40fc94527c59158080dfa2c0d822a0ffba2d341ecbce83151
#> ✖ Current schema digest:
#>   sha256:1bfa5c739d9a924fa3af797ed463d1c5383e3ae77c47a8cd4eebc5d23d5bf19f
#> ℹ Start a new `checkpoint_path` or pass `resume = FALSE` to overwrite.
```

### Offline Troubleshooting Checklist

- **Proxy Pre-Flight Failure (`env_proxy_isolation`)**: On institutional
  HPC login nodes that export `HTTP_PROXY` / `HTTPS_PROXY`, either unset
  proxy variables inside your Slurm job script
  (`unset HTTP_PROXY HTTPS_PROXY ALL_PROXY`) or explicitly include
  `NO_PROXY=127.0.0.1,localhost`.
- **Legacy Clinical CSV Encoding Errors**: `airgapllm` automatically
  normalizes Windows-1252 smart quotes and Latin-1 characters to valid
  UTF-8 prior to PII scanning and JSON serialization.
- **Symlinked Scratch Directories**:
  [`verify_model_digest()`](https://marcusharrisphd.com/airgapllm/reference/verify_model_digest.md)
  blocks symlinks escaping `model_dir` by default
  (`allow_symlinks = FALSE`); store canonical weight files directly
  inside the bound model directory.
