# Emit an HPC Apptainer Definition File (`.def`)

Generates a reproducible Apptainer definition recipe pinning the
upstream container image by SHA-256 digest, configuring offline
environment flags, recording provenance labels, and documenting the
air-gapped HPC execution command
(`apptainer run --containall --no-home --net --network none`).

## Usage

``` r
emit_apptainer_def(spec, file = NULL, require_pinned = TRUE)
```

## Arguments

- spec:

  An
  [`airgap_container_spec()`](https://marcusharrisphd.com/airgapllm/reference/airgap_container_spec.md)
  object.

- file:

  Optional path to write the `.def` recipe.

- require_pinned:

  Logical scalar; abort if `spec$image_digest` is missing. Defaults to
  `TRUE`.

## Value

A character scalar containing the Apptainer `.def` recipe.

## Examples

``` r
spec <- airgap_container_spec(
  backend = "ollama",
  image_digest = paste0("sha256:", strrep("d", 64)),
  model_dir = "/scratch/lab/models",
  gpu = "nvidia"
)
cat(emit_apptainer_def(spec))
#> # Generated by airgapllm 0.5.0
#> # Air-gapped HPC execution command:
#> #   apptainer build airgapllm-ollama.sif airgapllm.def
#> #   apptainer run --containall --no-home --net --network none --nv --bind '/scratch/lab/models:/models:ro' airgapllm-ollama.sif
#> 
#> Bootstrap: docker
#> From: ollama/ollama@sha256:dddddddddddddddddddddddddddddddddddddddddddddddddddddddddddddddd
#> 
#> %labels
#>     org.airgapllm.generator airgapllm-0.5.0
#>     org.airgapllm.backend ollama
#>     org.airgapllm.spec_digest sha256:35c4eff2bbbcabc7305d4a7739ec383cec5df51fdef06acb8d7b4486ad61e680
#>     org.airgapllm.network_mode none
#> 
#> %environment
#>     export DO_NOT_TRACK='1'
#>     export HF_DATASETS_OFFLINE='1'

#>     export OLLAMA_HOST='127.0.0.1:11434'
#>     export OLLAMA_MODELS='/models'
#>     export OLLAMA_NOHISTORY='1'
#>     export TRANSFORMERS_OFFLINE='1'
#> 
#> %post
#>     mkdir -p /models
#>     chmod 755 /models || true
#> 
#> %runscript
#>     exec ollama 'serve' "$@"
```
