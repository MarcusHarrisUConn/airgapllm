# Emit a Hardened Docker Compose YAML Configuration

Generates a Docker Compose specification enforcing read-only root
filesystems, dropped capabilities, `no-new-privileges`, pinned image
digests, offline environment variables, read-only model volume mounts,
and air-gapped networking (`network_mode: none` or an `internal: true`
network).

## Usage

``` r
emit_docker_compose(
  spec,
  file = NULL,
  service_name = NULL,
  require_pinned = TRUE
)
```

## Arguments

- spec:

  An
  [`airgap_container_spec()`](https://marcusharrisphd.com/airgapllm/reference/airgap_container_spec.md)
  object.

- file:

  Optional file path to write the Compose YAML.

- service_name:

  Optional Compose service name. Defaults to
  `paste0("airgap-", gsub("[^a-z0-9]+", "-", spec$backend))`.

- require_pinned:

  Logical scalar; abort if `spec$image_digest` is missing. Defaults to
  `TRUE`.

## Value

A character scalar containing valid Docker Compose YAML.

## Examples

``` r
spec <- airgap_container_spec(
  backend = "vllm",
  image_digest = paste0("sha256:", strrep("c", 64)),
  model_dir = "/srv/models",
  model_file = "qwen2.5-7b-instruct",
  gpu = "nvidia"
)
cat(emit_docker_compose(spec))
```
